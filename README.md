# 304 麻将积分查询

通过 GitHub Pages 发布的只读查询前端，自动加载 `data.json`。

- 所有学期排行榜沿用换学期积分减半规则；单学期仅累计该学期得分。
- 两两同桌分数差为所有同桌对局的 `Σ(A.finalScore - B.finalScore)`，包含顺位分，不因换学期减半。
- 选手详情可独立筛选选手和学期：显示位次分布、一位率、连对率、避四率、平均顺位、平均素点得失、场均得分及个人对局明细。
- 最近十场顺位与得分折线图按本人参赛顺序排列，顺位图的一位在上方；不足十场按实际场次显示，点击或聚焦图上的点可查看该场信息。
- 近期 10／20 场、连续纪录、最高／最低点数与得分、得分波动、扣分统计按所选范围计算。对手表现固定使用所有学期，与两两同桌分数差一致。
- 保留历史对局和学期奖项；访客无数据录入、导入、结算或保存入口。

## 选手统计口径

表现指标按原始对局计算，不应用学期减半；“当前累计积分”单独显示，沿用排行榜的减半规则。连对指前二，避四指前三，所有比率均显示实际样本数。平均素点得失为 `平均(终局点数 - 25000)`，单位为点。场均得分与得分走势使用 `finalScore`，已包含顺位分及违规扣分，不重复扣罚；扣罚前场均得分使用 `finalScore - penalty`。

原点以上率使用终局点数 `> 25000`，正得分率使用 `finalScore > 0`，负点结束率使用终局点数 `< 0`。得分波动为所选样本的总体标准差，不足两场显示空值。连续纪录按本人参与的对局序列计算；对手顺位领先率按两人同桌时本人顺位更高的场数计算。现有数据只包含半庄结果，不统计和牌率、放铳率等局内数据。

## 更新数据

仓库所有者在本地计分器录入并导出 JSON 后，用导出文件替换 `data.json`，提交并通过 SSH 推送到 `main`。GitHub Pages 会更新站点。`data.json` 保留完整的 `records` 和学期切换记录，页面从记录重新计算统计。

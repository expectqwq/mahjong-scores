# 304 麻将积分查询

通过 GitHub Pages 发布的只读查询前端，自动加载 `data.json`。

- 所有学期排行榜沿用换学期积分减半规则；单学期仅累计该学期得分。
- 两两同桌分数差为所有同桌对局的 `Σ(A.finalScore - B.finalScore)`，包含顺位分，不因换学期减半。
- 页首导航按页面顺序排列：排行榜、选手查询、同桌分数差、历史记录。
- 选手详情可独立筛选选手和学期：所有个人指标集中在顶部，卡片仅显示名称和数值，包括场次、一位率、连对率、避四率、平均顺位、平均素点得失、场均得分、范围内总得分、当前累计积分、被飞率和违规扣分，下方展示位次分布。
- 选手查询和同桌分数差均使用页面内选人名单，点击后在控件下方展开并可滚动，选中后收起；支持方向键、Enter 和 Esc。
- 位次分布为一条合计 100% 的堆叠条，按实际场次占比分段；图例显示各位次的比例和场数，百分比显示值四舍五入。
- 最近十场顺位折线图按本人参赛顺序排列，一位在上方；不足十场按实际场次显示，点击或聚焦图上的点可查看该场信息。
- 保留历史对局和学期奖项；访客无数据录入、导入、结算或保存入口。

## 选手统计口径

表现指标按原始对局计算，不应用学期减半；“当前累计积分”单独显示，沿用排行榜的减半规则。连对指前二，避四指前三，页内显示所选范围的实际场次。平均素点得失为 `平均(终局点数 - 25000)`，单位为点。场均得分使用 `finalScore`，已包含顺位分及违规扣分，不重复扣罚。

被飞率为终局点数 `< 0` 的场数占所选范围场次的比例。现有数据只包含半庄结果，不统计和牌率、放铳率等局内数据。

## 更新数据

仓库所有者在本地计分器录入并导出 JSON 后，用导出文件替换 `data.json`，提交并通过 SSH 推送到 `main`。GitHub Pages 会更新站点。`data.json` 保留完整的 `records` 和学期切换记录，页面从记录重新计算统计。
